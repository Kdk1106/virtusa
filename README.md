# Virtusa Programming Questions

This repository contains my solutions for the programming questions given for Virtusa practice and preparation.

I have implemented the programs using Java, TypeScript and JavaScript. The solutions are kept simple and focus on basic logic, clean code and reasonable time complexity.

## Programs

### Java
- Count the number of words in a sentence
- Print Pascal's Triangle up to N rows

### TypeScript
- Demonstrate single inheritance
- Implement a stack using an array
- Find the average of elements in an array
- Check whether a number is even or odd

### JavaScript
- Format a Date as YYYY-MM-DD
- Find unique values in an array using Set
- Capitalize the first letter of each word in a sentence

## Time Complexity

| Program | Time Complexity |
|---|---|
| Count Words | O(n) |
| Pascal's Triangle | O(n²) |
| Stack Operations | O(1) |
| Array Average | O(n) |
| Even / Odd | O(1) |
| Date Formatting | O(1) |
| Unique Values | O(n) |
| Capitalize Words | O(n) |
