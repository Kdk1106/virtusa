# Virtusa Programming Questions

This repository contains my solutions for the programming questions given for Virtusa practice and preparation.

The programs are written in Java, TypeScript and JavaScript. I have kept the code simple and focused on basic logic and time complexity.

## Programs

### Java

#### 1. Count the number of words in a sentence

**Input**
```text
Java is easy to learn
```

**Output**
```text
Number of words: 5
```

#### 2. Pascal's Triangle

**Input**
```text
5
```

**Output**
```text
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

### TypeScript

#### 1. Single Inheritance

**Output**
```text
Animal is eating
Dog is barking
```

#### 2. Stack using an Array

**Output**
```text
Top: 30
Popped: 30
[10, 20]
```

#### 3. Average of Array Elements

**Output**
```text
Average = 30
```

#### 4. Even or Odd

**Output**
```text
Odd
```

### JavaScript

#### 1. Date Formatting

**Output**
```text
2026-10-05
```

#### 2. Unique Values using Set

**Output**
```text
[10, 20, 30, 40]
```

#### 3. Capitalize the First Letter of Each Word

**Output**
```text
Hello World From Javascript
```

## Time Complexity

| Program | Time Complexity | Space Complexity |
|---|---:|---:|
| Word Count | O(n) | O(1) |
| Pascal's Triangle | O(n²) | O(1) |
| Stack Operations | O(1) per operation | O(n) |
| Array Average | O(n) | O(1) |
| Even / Odd | O(1) | O(1) |
| Date Formatting | O(1) | O(1) |
| Unique Values | O(n) expected | O(n) |
| Capitalize Words | O(n) | O(n) |
